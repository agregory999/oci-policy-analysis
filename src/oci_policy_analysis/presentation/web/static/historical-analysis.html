Find OCI Audit Records (Logging Search)

Generate Logging Search commands to run yourself; no OCI calls are performed. Use the policy/resource compartment and appropriate region. Resource filtering runs on the server. Policy searches include only CreatePolicy, UpdatePolicy and DeletePolicy attempts; check status for success. Tables show formatted time with timezone, operation, actor name/OCID, IP and status. Each command returns at most 100 results, newest first, not a complete history. Narrow the time range or use --page with the response opc-next-page token (remove --query and use --output json to see response metadata). Audit read permission is required; IAM domain activity may require its domain audit report.
