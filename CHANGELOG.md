## [1.0.0] - 2025-07-14

### Added
- Analysis of Users, Resource Principals, Cross-tenancy policies
- More filtering and sorting options
- Dynamic versioning using setuptools_scm and semantic-release
- Multi-platform executable builds with PyInstaller

## [0.1.0] - 2024-09-03

### Added
- Initial release of OCI Policy and Dynamic Group Viewer
- Support for policy and compartment analysis with GUI and CLI interfaces
- Caching, Filtering, Export
