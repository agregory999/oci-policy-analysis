# OCI Policy Analysis

Analyze Oracle Cloud IAM policies and identity data.

📘 **Full documentation:**  
👉 [https://andrewgregory.github.io/oci-policy-analysis](https://andrewgregory.github.io/oci-policy-analysis)

## Quick Start
```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -e .
python -m oci_policy_analysis
```
Or run a packaged release:
```bash
oci-policy-analysis.exe   # Windows
./oci-policy-analysis.app # macOS
```
