# Maintainer Context

This directory contains the living design, architecture, coding, and feature
context used by maintainers and development agents.

It is intentionally separate from `docs/source/`: the files remain versioned
and available in the repository, but are not part of the published Sphinx user
documentation or its navigation.

## Contents

- [`generic/`](generic/): reusable documentation and coding conventions.
- [`project/`](project/): OCI Policy Analysis architecture, feature, and
  subsystem context.

Context documents may describe rationale, planned work, and implementation
details that are more detailed or more speculative than the user documentation.
When they conflict with source code, the source tree and published API
reference are authoritative.
