OCI Policy Analysis

Analyze Oracle Cloud IAM policies and identity data.

📘 Full documentation: 👉 https://agregory999.github.io/oci-policy-analysis

Quick Start

python3 -m venv .venv
source .venv/bin/activate
pip install -e .
python -m oci_policy_analysis

Or run a packaged release:

oci-policy-analysis.exe   # Windows
./oci-policy-analysis.app # macOS
